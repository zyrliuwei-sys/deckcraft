## What this site does

DeckCraft.me helps people get started with the DeckCraft presentation application. The site brings together download instructions, practical slide-making guides, file compatibility checks, and a browser editor you can try without installing a desktop application. Its purpose is to help you make an informed choice and complete a usable presentation, including saving and checking the result.

Start with the [guides](/guides), follow the [tutorials](/tutorials), or open the [online editor](/app). The [download page](/download) links to releases hosted by the upstream project. Downloaded applications and third-party services have their own documentation and policies.

## Who maintains this site

DeckCraft.me is maintained by an independent developer. This website does not present itself as a company, an editorial team, or the developers of the upstream application. No professional credentials or affiliation are claimed.

Questions about the website, corrections, and accessibility problems can be sent through the email address on the [contact page](/contact).

## How the content is prepared

The guides are manually organized from official project documentation and actual use of the software. Articles link to relevant primary sources and distinguish documented behavior from observations made in a particular version or environment. Practical checks describe their scope so a reader can repeat them with a copy of their own presentation.

An application opening a file is not evidence that every animation, font, or layout survives unchanged. When a feature or delivery scenario has not been checked, the content labels it **not verified**. Example workflows are instructional examples, not invented customer results or compatibility percentages. Screenshots illustrate the stated interface or example; they are not proof of universal file fidelity.

Release notes and the independently hosted browser editor can change on different schedules. A current desktop download link does not imply that the browser editor has been upgraded to that release. Each guide's update date helps identify when its content was last reviewed.

## Independence

This is an independent third-party guide to DeckCraft. It is not affiliated with, endorsed by, or operated by the DeckCraft project or its developers.

DeckCraft and other product names are used to identify the software discussed. For the application source, releases, and upstream issue reporting, visit the [DeckCraft project repository](https://github.com/storytold/deckcraft).
